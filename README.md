Названия проекта:  Kanban HR

Описание выполненной работы. Создано WPF-приложение "Kanban HR" для управления персоналом с системой авторизации. Разработаны две основные страницы: LoginPage для входа в систему с полями логина и пароля, кнопкой "Войти" и ссылкой на регистрацию; RegistrationPage для создания нового аккаунта с полями ФИО, Email, Пароль и Подтверждение пароля, кнопкой "Зарегистрироваться" и проверкой совпадения паролей. Реализована навигация между страницами. Применена цветовая палитра со светлым лавандовым фоном (#FFEDE7F6), фиолетовым акцентом (#FF7B1FA2) и деловым синим цветом (#FF0277BD). Использованы профессиональные шрифты Segoe UI. Подготовлена структура для логотипа в формате PNG и иконки приложения в формате ICO. Все стили изначально были централизованы в App.xaml, но из-за ошибок ресурсов переделаны во встроенные стили непосредственно в XAML-файлах страниц. Реализована базовая валидация: проверка заполнения полей и совпадения паролей при регистрации с выводом соответствующих сообщений. Добавлены интерактивные элементы с визуальными эффектами при наведении и нажатии. Созданы все необходимые файлы: App.xaml/.cs для ресурсов и запуска приложения, MainWindow.xaml/.cs как главное окно-контейнер, а также XAML и C# файлы для обеих страниц. Приложение полностью собрано и готово к запуску, требует только добавления графических файлов логотипа и иконки, а также реализации backend-логики для работы с данными пользователей.
